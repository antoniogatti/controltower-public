# 🌍 UAE Trip 2026 - Interactive Trip Planner

A beautiful, fully responsive trip planning system for Antonio Gatti's UAE adventure (Dec 25, 2026 - Jan 2, 2027).

**🎯 Booking Reference:** `VWRH8U`  
**✈️ Travelers:** Antonio Gatti, Lucia Saracino, Elio Saracino Gatti

---

## 🌟 Features

### 📸 Trip Gallery (`trip-gallery.html`) — START HERE
- **18 destination cards** across 3 cities (Dubai, Abu Dhabi, Istanbul)
- **Interactive SVG map** showing your trip route with color-coded markers
- **Hotel information** for each destination
- **Quick access** to trip calendar
- **Responsive design** (mobile, tablet, desktop)

### 📅 Interactive Calendar (`trip-calendar.html`)
- **9-day drag-and-drop planner** (Dec 25 – Jan 2)
- **Pre-populated** flights, hotels, desert safari
- **Hotel info** at top of each day
- **Add/edit/delete** activities
- **Color-coded** by type (flights, hotels, activities)
- **Share** with Lucia via link
- **Auto-save** to browser
- **Works offline**

### 📋 Trip Book (`index.html`)
- **Premium trip overview**
- **All bookings** and confirmations
- **Quick action links**
- **Beautiful Mobbin-inspired design**

## 🌐 Deploy to GitHub Pages

### Method 1: Use GitHub Web Interface
1. Go to https://github.com/new
2. Create repository: `uae-trip-2026` (Public)
3. Upload files via web interface
4. Settings → Pages → Deploy from main branch
5. Live at: `https://YOUR_USERNAME.github.io/uae-trip-2026/`

### Method 2: Use Git CLI
```bash
# In the project directory
git init
git add .
git commit -m "UAE Trip 2026: Interactive trip planner"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/uae-trip-2026.git
git push -u origin main

# Then enable Pages in GitHub Settings
```
